# Release 2.0.0

This major release replaces the earlier broad seven-cohort presentation with the focused three-cohort Research Article analysis. It adds the completed 35-participant Dryad sensor-space robustness analysis, metric- and aggregation-matched external validity tests, a unified participant-level prediction audit, participant-bootstrap uncertainty summaries, four focused figures with source data, and the corresponding regression tests.

The inferential boundary is unchanged by packaging: stimulus-locked target engagement, reliability, concurrent validity, and incremental prediction are treated as separate claims. The spatial analysis is explicitly classified as post-result robustness analysis.

The final Git commit, Git tag, and Zenodo version DOI will be inserted after archive publication.
