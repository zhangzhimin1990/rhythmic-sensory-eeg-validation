# Code availability

The repository contains author-generated analysis code, frozen protocols, targeted automated tests, minimized deidentified derived inputs, machine-readable results, and figure source data for the focused three-cohort article. Raw EEG is not redistributed and must be obtained from the source repositories.

The immutable v2.0.0 archive is available through Zenodo at https://doi.org/10.5281/zenodo.24065026. The version-independent concept DOI is https://doi.org/10.5281/zenodo.23137957.
